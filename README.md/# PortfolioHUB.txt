# PortfolioHUB

Este repositório reúne meus projetos acadêmicos e pessoais desenvolvidos durante minha trajetória na área de Tecnologia da Informação.

## Sobre mim

Sou João Pedro, estudante da área de TI, com interesse em desenvolvimento, banco de dados, segurança da informação e criação de projetos digitais.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- SQL
- Git
- GitHub

## Estrutura do repositório

- `projetos-academicos/`: trabalhos e atividades desenvolvidas na faculdade.
- `projetos-pessoais/`: projetos criados por interesse próprio.
- `slides/`: apresentações utilizadas nos projetos.
- `documentos/`: arquivos de apoio e documentação.
- `assets/`: imagens utilizadas no repositório.

# DER - Seguradora

## Descrição

Projeto acadêmico de modelagem de banco de dados para uma companhia de seguros de automóveis.

## Objetivo

Modelar entidades, relacionamentos, atributos e cardinalidades para o sistema da seguradora.

## Conteúdo

- Clientes
- Veículos
- Acidentes
- Relacionamentos
- Cardinalidades

## Ferramentas Utilizadas

- Draw.io
- MySQL Workbench
- GitHub

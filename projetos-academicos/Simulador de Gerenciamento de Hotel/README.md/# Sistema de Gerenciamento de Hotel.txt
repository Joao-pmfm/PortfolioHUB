# Sistema de Gerenciamento de Hotel

## Descrição

Projeto acadêmico de modelagem de banco de dados para um sistema de gerenciamento hoteleiro.

## Objetivo

Desenvolver a estrutura de um banco de dados capaz de organizar informações relacionadas ao funcionamento de um hotel.

## Conteúdo Modelado

- Hóspedes
- Quartos
- Reservas
- Funcionários
- Pagamentos
- Serviços
- Check-in e Check-out

## Conceitos Aplicados

- Entidades
- Relacionamentos
- Cardinalidades
- Chaves primárias e estrangeiras
- Modelagem DER

## Ferramentas Utilizadas

- Draw.io
- MySQL Workbench
- GitHub

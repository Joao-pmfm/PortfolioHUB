# Projetos Acadêmicos

Esta pasta reúne projetos e atividades desenvolvidos durante minha trajetória acadêmica na área de Tecnologia da Informação.

## Objetivo

Organizar e documentar projetos acadêmicos aplicando conceitos de desenvolvimento, modelagem, documentação e versionamento utilizando Git e GitHub.

## Conteúdo

### Modelagem de Banco de Dados
Projetos de modelagem utilizando Diagramas Entidade-Relacionamento (DER), abordando entidades, relacionamentos, atributos e cardinalidades.

#### Projetos incluídos
- DER - Seguradora
- DER - Sistema Hospitalar
- Gerenciamento de Hotel

### Segurança da Informação
Projeto acadêmico focado em práticas e conceitos fundamentais de segurança da informação em ambientes corporativos.

### Arquitetura de Computadores
Projetos e atividades relacionados à organização e arquitetura de computadores, incluindo memória, álgebra booleana e lógica computacional.

## Tecnologias e Ferramentas Utilizadas

- Git
- GitHub
- Draw.io
- MySQL Workbench
- HTML
- CSS

# DER - Seguradora

## Descrição

Projeto acadêmico de modelagem de banco de dados para uma companhia de seguros de automóveis.

## Objetivo

Identificar entidades, atributos, relacionamentos, cardinalidades e identificadores.

## Conteúdo

- Modelo Entidade-Relacionamento
- Entidades
- Atributos
- Cardinalidades
- Relacionamentos

## Ferramentas utilizadas

- Draw.io
- MySQL Workbench
- GitHub

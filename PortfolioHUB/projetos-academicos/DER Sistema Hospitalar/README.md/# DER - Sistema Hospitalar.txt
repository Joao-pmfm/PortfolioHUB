# DER - Sistema Hospitalar

## Descrição

Projeto acadêmico de modelagem de banco de dados para um ambiente hospitalar.

## Objetivo

Estruturar entidades e relacionamentos relacionados a médicos, pacientes, quartos e cirurgias.

## Conteúdo

- Médicos
- Pacientes
- Quartos
- Salas de cirurgia
- Especializações

## Ferramentas Utilizadas

- Draw.io
- GitHub
